# Courses Home

Home Repo for my university teaching work. Holds shared skills, `AGENTS.md` and shared docs, and points at the course repos (it does not contain them). Run the agent from this folder. `AGENTS.md` is the entry point; `CLAUDE.md` points to it.

## Clone

```
git clone git@github.com:AndreasArne/work.git ~/work
```

The course repos (`devops/`, `mvc/`) are cloned inside `~/work` but gitignored. `AGENTS.md` lists where each one is cloned from.
